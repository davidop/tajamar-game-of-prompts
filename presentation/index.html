⚡ GSD Core

Ingeniería de contexto, fases y verificación del trabajo.

Mismo agente (Copilot CLI); cambia el método, no el motor.

Min 30–45

Primero, las leyes del reino

  • Lee el PRD completo.
  • Crea especificación, plan y tareas usando tu framework.
  • Registra supuestos si algo es ambiguo.
  • Conserva artefactos, no te limites a pedir «haz la app».
Min 45–75

¡A construir!

  • Implementa en incrementos verificables.
  • Comprueba los requisitos, no solo la estética.
  • Respeta los data-testid.
  • Si falla, diagnostica y corrige; no ocultes errores.
npm run dev npm run build
Min 75–90
