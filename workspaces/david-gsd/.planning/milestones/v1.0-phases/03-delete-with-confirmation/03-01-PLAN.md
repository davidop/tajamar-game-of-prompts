## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering (XSS) | confirmDialog message with task title | mitigate | Set message via textContent only; smoke test already forbids innerHTML in src |
| T-03-02 | Tampering | accidental data loss on delete | mitigate | Deletion only after confirm-delete resolves true (D-03); cancel/Esc resolve false |
| T-03-03 | Denial of service | deleteTask with unknown/stale id | mitigate | Returns { ok: false } with no write or notify; covered by test |
| T-03-04 | Information disclosure | remote calls | accept | App is static/local; smoke test already forbids fetch and remote URLs |
