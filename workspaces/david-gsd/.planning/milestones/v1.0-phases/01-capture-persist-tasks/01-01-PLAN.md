Contracts (create exactly; downstream plan and phases 2-3 rely on them):
- Task shape (D-03): id (string), title (trimmed), description (string, trimmed, may be ''), status 'pending'|'completed', createdAt (ISO string).
- validateTitle(raw) returns { valid: boolean, value: string, error: string|null }; trims first; valid iff 3 <= length <= 80 inclusive.
- createTask(title, description) returns a Task with status 'pending'; id from crypto.randomUUID() when available, else Date.now()+counter fallback.
- loadTasks(storage = globalThis.localStorage) returns an array, never throws; saveTasks(tasks, storage) returns boolean, wraps setItem in try/catch.
- createStore(initialTasks, storage) returns { getTasks(), addTask(title, description) -> { ok, error? }, subscribe(fn) -> unsubscribe }. addTask validates via validateTitle, appends, calls saveTasks, notifies. Store is the only module calling saveTasks (D-02).
</context>
