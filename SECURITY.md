# Seguridad para el taller

La aplicación se ejecuta solo en localhost, sin cuentas ni claves. No añadas secretos o API keys a commits ni al chat de Copilot. Revisa cada comando o acceso a herramientas que solicite el agente, especialmente operaciones destructivas o sobre el sistema de archivos. No habilites aprobación global de comandos solo para ganar tiempo.

Si detectas un fallo de seguridad, notifícalo a los facilitadores y evita publicar credenciales o exploits en issues.
