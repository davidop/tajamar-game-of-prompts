# Contribuir

Bienvenidas correcciones al material docente: documentación, accesibilidad, tests o mejoras del starter.

- Mantén **sin implementación** `starter/`; las soluciones de los alumnos se desarrollan en sus workspaces.
- No publiques la petición sorpresa ni instrucciones detalladas de la misma antes de impartir la sesión.
- Valida `npm run check` desde la raíz y `npm run build` desde `starter` antes de abrir un PR.
- Evita dependencias innecesarias, credenciales, código privativo e imágenes con derechos no concedidos.
- Toda mejora de la evaluación debe mantener el mismo contrato para ambas casas.
