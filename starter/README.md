# TaskForge — starter deliberadamente vacío

Este proyecto Vite **arranca y construye**, pero no implementa la aplicación: esa es tu misión.

- Lee el PRD copiado en `docs/02-documento-funcional.md` por `npm run setup` desde la raíz.
- Respeta los `data-testid` de la sección de testabilidad; el diseño y la arquitectura son libres.
- No añadas backend ni persistencia externa. El MVP usa `localStorage`.

```bash
npm install
npm run dev
npm run build
```

No utilices una solución de referencia; documenta decisiones y pruebas con la casa elegida.
